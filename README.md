# Modelling Student Behaviour Using Machine Learning
### A Data-Driven Approach to Academic Performance Prediction

This repository presents my research paper, **"Modelling Student Behaviour Using Machine Learning: A Data-Driven Approach to Academic Performance Prediction,"** which explores a conceptual machine learning framework for analysing student behaviour and its potential relationship with academic performance.

The research paper was presented at an international conference.

---

## 📌 Research Overview

Students' daily routines, study habits, screen time, sleep patterns, and other behavioural factors can influence their learning experiences and academic development.

This research proposes a data-driven framework that uses machine learning techniques to analyse student behavioural patterns, identify potentially unhealthy routines, and support educators and parents in understanding factors associated with academic performance.

The framework focuses on students across Grades 1–10 and emphasizes interpretability, scalability, and responsible handling of student data.

## 🎯 Research Objectives

- Analyse student behavioural patterns and daily time-use habits.
- Explore the relationship between behavioural factors and academic performance.
- Propose a machine learning framework for identifying behavioural patterns.
- Explore classification and clustering techniques for student behaviour analysis.
- Support data-driven educational decision-making.
- Emphasize explainability and privacy-aware handling of student information.

## 🧠 Machine Learning Techniques

The proposed conceptual framework considers the following techniques:

| Technique | Purpose |
|---|---|
| Random Forest | Analyse structured behavioural data and support classification. |
| XGBoost | Explore classification and predictive modelling. |
| Long Short-Term Memory (LSTM) | Consider temporal patterns in student activities. |
| K-Means Clustering | Group students according to behavioural similarities. |
| Explainable AI (XAI) | Improve the interpretability of analytical outputs. |

**Note:** These techniques are proposed as part of the conceptual framework. The models have not been implemented or experimentally evaluated in this study.

## ⚙️ Proposed Methodology

The framework follows a conceptual, multi-stage workflow:

1. **Data Collection:** Identify potential data sources, including surveys, learning platforms, and student activity records.
2. **Data Preprocessing:** Clean, organize, and transform behavioural data.
3. **Exploratory Data Analysis:** Examine patterns, distributions, and relationships.
4. **Feature Engineering:** Prepare relevant behavioural features for analysis.
5. **Machine Learning:** Apply suitable classification and clustering approaches.
6. **Explainability:** Explore methods for interpreting model outputs.
7. **Educational Analytics:** Present potential insights through an educator-oriented dashboard.

The proposed workflow provides a foundation for future implementation and validation in educational environments.

Student behavioural data can be sensitive. Any future implementation should consider data privacy, informed consent, secure data handling, and responsible interpretation of model predictions.

The framework is intended to support educational understanding and decision-making, not to label or penalize students based on their behaviour.
